# v3.1.0

> [!WARNING]
> 此版本属于 3.x 完整方案。必须先刷入同一 Release 的 `boot-ACLaniakea-*.img` 与 `vendor_boot-hyperSched-stub.img`，且两者必须成对使用；随后再安装 KernelSU 模块与 LSPosed APK。

## 更新摘要

- 新增 CryptoEng 兼容模块，用于查找设备与一加互传联系人发现。
- 主修复模块新增前摄 RGB 指示灯支持。
- 改进手电筒亮度控制。

## 主要改动

### CryptoEng 兼容

`CryptoengHAL-Module` 保持现有查找设备链路，并补齐联系人发现所需的兼容能力。仅在需要查找设备或一加互传时安装。

### 前摄指示灯

主修复模块会随前摄使用状态控制物理指示灯，不再需要单独安装 LED 模块。

### 手电筒亮度

手电筒亮度继续通过现有 SystemUI 集成提供，并改善了档位切换体验。

## 安装

先成对刷入本 Release 的 `boot` 与 `vendor_boot`，再安装同版本的 `FixModule` 与 `BaseFix-Hook`；需要时再安装 `CryptoengHAL-Module`，然后完整重启。完整安装顺序和兼容性要求见项目 [README](../README.md)。

## 说明

- 联系人发现仍需要两端满足正常的账号、网络和联系人匹配条件。
- 如需回退 CryptoEng 兼容功能，只需在 KernelSU 停用或移除 `cryptoeng_hal_fix` 后重启。
