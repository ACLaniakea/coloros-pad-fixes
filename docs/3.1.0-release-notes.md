# v3.1.0

3.x 完整方案的功能补充：新增 CryptoEng 兼容模块，主修复纳入前摄指示灯与手电筒亮度控制。

> [!WARNING]
> 必须先成对刷入同一 Release 的 `boot-ACLaniakea-*.img` 与 `vendor_boot-hyperSched-stub.img`，再安装 KernelSU 模块与 LSPosed APK。

## 更新内容

### CryptoEng 兼容

新增 `CryptoengHAL-Module`，在保持查找设备链路的同时补齐一加互传联系人发现所需的兼容能力。仅在需要这两项功能时安装；停用该模块并重启即可回退。

联系人发现仍需两端满足正常的账号、网络与联系人匹配条件。

### 前摄指示灯

主修复模块随前摄使用状态控制物理指示灯，不再需要单独的 LED 模块。

### 手电筒亮度

改善档位切换体验，继续通过现有 SystemUI 集成提供。

## 安装或升级

先成对刷入本 Release 的 `boot` 与 `vendor_boot`，再安装同版本 `FixModule` 与 `BaseFix-Hook`，按需追加 `CryptoengHAL-Module`，然后执行一次完整重启。

完整安装顺序与兼容性要求见 [README](../README.md)。
