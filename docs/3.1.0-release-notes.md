# 3.1.0 发布说明

## 主要更新

- 新增 `CryptoengHAL-Module` 分流代理：保留已验证的查找设备软件 HAL
  命令链路，并补齐一加互传联系人模式依赖的 CryptoEng PKI 调用。
- 联系人模式的 `10003 PkiHkdf` 改为使用设备随附 OPlus CryptoEng
  provisioning 数据动态派生；随机 salt 每次变化时均可正确处理。
- 前摄指示灯并入主 `FixModule`：前摄实际使用期间点亮 RGB 白灯，释放后熄灭；
  排除人脸解锁与 AON 误触发场景。
- 手电筒亮度改为 0–100 驱动电流全范围分级，低档位不再爆闪。
- 所有主模块版本统一至 `3.1.0`（`versionCode=301000`）。

- 查找设备注册与定位：已通过。
- 一加互传联系人 Beacon：已完成 10003 动态派生与 BLE 广播验证。
- 前摄指示灯与手电筒分级：已在设备端验证。
