# v3.2.0

将主修复、手写笔桥接、调度、BSP、CryptoEng 与 ZUI 相机统一到同一版本线（`3.2.0 / 302000`）。

> [!WARNING]
> 必须先成对刷入同一 Release 的 `boot-ACLaniakea-*.img` 与 `vendor_boot-hyperSched-stub.img`，再安装 KernelSU 模块与 LSPosed APK。

## 相比 v3.1.0

### 相机与 AON

- 改进移植系统上的相机服务稳定性。
- 恢复普通相机与 AON 注视感知之间的相机占用切换，AON 保持硬件 QNN/DSP 路径。
- 前摄物理指示灯修复继续包含在主模块中。

### ZUI 相机移植

- 新增可选的 `LenovoPadProGT-ZUI-Camera-Port` 与 `ZUI-Camera-Compat`，仅适用于 TB710FU。
- 兼容层只作用于 `com.zui.camera`，不替换 camera provider、CamX 或全局设备身份。
- 增加 ColorOS 相册入口与所需的平板相机配置。

### 打包与作用域

- 所有模块与配套 APK 统一版本号、名称及 LSPosed 推荐作用域。
- ZUI 兼容代码从基础 Hook 拆出，仅由独立 ZUI Hook 提供。
- 统一手写笔组件的源码构建入口。

## 安装或升级

请只使用同一 v3.2.0 Release 的产物。先成对刷入配套 `boot` 与 `vendor_boot`，再安装主修复模块与 BaseFix Hook，最后按需增加其他组件。

目标设备为联想小新 Pad Pro GT（TB710FU / SM8650Q / pineapple），ROM 为 ColorOS 16 移植包 OPD2513。模块选择与回退方式见 [README](../README.md)。
