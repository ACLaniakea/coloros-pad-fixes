# v3.2.1

整合发布：所有模块与配套 APK 统一为 `3.2.1 / 302001`，CryptoEng 修复并入主修复模块。

> [!NOTE]
> 本次未变更内核。Release 中的 `boot` 与 `vendor_boot` 与 v3.2.0 内容相同，仍须成对刷入。

## 相比 v3.2.0

### CryptoEng 并入主修复

- `FixModule` 内置 CryptoEng 分流代理：命令 10003 在本地实现，其余请求继续走已验证的软件 HAL 路径。
- 安装主模块会停用旧的独立 `cryptoeng_hal_fix`，避免两个代理竞争同一 HAL 服务。
- 查找设备、密码本云同步与一加互传联系人所需的兼容路径保持不变。

### 构建与交付

- 全部模块、Hook 与 APK 由当前源码重新构建。
- 构建入口兼容仓库内最小 Android SDK，避免工作站缺少新版 build-tools 时无法复现。
- ZUI 相机的原厂 APK 仅作为构建输入与发布附件，不纳入源码仓库。

## 安装或升级

请使用同一 v3.2.1 Release 的产物。安装 `FixModule` 后不要再安装旧的 `CryptoengHAL-Module`。

安装完 KernelSU 模块与 APK 后执行一次**完整重启**，不要仅重启 zygote。
