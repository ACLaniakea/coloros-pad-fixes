# 4.1.3

本版只修正刷新率策略，不改变面板能力、内核或内存参数。

## 刷新率

移植 ROM 的 `refresh_rate_config.xml` 缺少 144Hz mode 声明时，用户手动选择最高
刷新率会让 `rateId=4` 落入错误降级路径。模块继续补齐
`8750R60_90_120_144`，但不再以此覆盖系统策略：

* 默认自动档恢复为 120Hz；
* 所有应用配置的自动字段 `rateId[0]` 由 144Hz 改为未指定，交还框架；
* 手动最高档的 `rateId[3]=4` 保留，因此只在用户手动选择最高档时请求 144Hz；
* 手写笔实际书写时仍通过原厂 `OplusRefreshRatePolicyImpl` 的
  `settings_enable_oppo_pencil` 投票使用 120Hz；
* PenBridge 不再读取或写入用户的 `min_refresh_rate`、`peak_refresh_rate`。

完整重启后，在显示设置中选择自动、60Hz、最高三个档位验证；自动档不应因桌面或普通
应用被强制为 144Hz，最高档应可正常启用 144Hz。

## 内存观察

本轮运行态检查未发现相机预填池泄漏。池已回填至 192MiB，预填线程空闲。当前系统
压力主要来自活跃工作集和图形映射；本版不以未经 A/B 的方式调整相机池容量或 swap
参数。
