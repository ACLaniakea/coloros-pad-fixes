# v3.2.1

v3.2.1 是一次整合发布：所有正式模块与配套 APK 统一为 `3.2.1 / 302001`，CryptoEng 修复纳入主修复模块。

## 相比 v3.2.0

### CryptoEng 与云端能力

- `FixModule` 内置 CryptoEng 分流代理：命令 10003 在本地实现，其余请求继续使用已验证的软件 HAL 路径。
- 安装主模块会停用旧 `cryptoeng_hal_fix` 独立模块，避免两个代理竞争同一 HAL 服务。
- 保留查找设备、密码本云同步及一加互传联系人所需的兼容路径。

### 构建与交付

- 主修复、手写笔三件套、BSP、Scene 调度、ZUI 相机移植及对应 LSPosed Hook 全部由当前源码重新构建。
- 构建入口兼容仓库内最小 Android SDK，避免因工作站缺少新版 build-tools 而无法复现。
- ZUI 相机的原厂 APK 仅作为 Release 构建输入和发布附件使用，不纳入源码仓库。

## 安装或升级

请使用同一 v3.2.1 Release 的产物。安装 `FixModule` 后不要再安装旧 `CryptoengHAL-Module`；它已并入主模块。

本次未变更配套内核，Release 中附带的 `boot` 与 `vendor_boot` 与 v3.2.0 内容相同，仍须成对使用。

安装完 KernelSU 模块与 APK 后执行一次**完整重启**，不要仅重启 zygote。
