# v3.2.0

v3.2.0 将主修复、手写笔桥接、调度、BSP、CryptoEng 与 ZUI 相机统一到同一版本线。

## 更新摘要

- 改进相机服务稳定性，以及 AON 与普通相机的共存。
- 为 TB710FU ZUI 相机移植提供独立、仅应用生效的兼容层。
- 统一模块与配套 APK 的版本、名称和 LSPosed 推荐作用域。
- 统一手写笔组件的源码构建入口。

## 相比 v3.1.0

### 相机与 AON

- 改进移植系统上的相机服务稳定性。
- 恢复普通相机与 AON 注视感知之间的相机占用切换。
- AON 保持使用硬件 QNN/DSP 路径。
- 前摄物理指示灯修复继续包含在主模块中。

### ZUI 相机移植

- 新增可选的 `LenovoPadProGT-ZUI-Camera-Port` 与 `ZUI-Camera-Compat`。
- 兼容层只作用于 `com.zui.camera`，不替换 camera provider、CamX 或全局设备身份。
- 增加 ColorOS 相册入口和所需的平板相机配置。

### 打包与作用域

- 所有发布模块和配套 APK 统一为 `3.2.0 / 302000`。
- BaseFix、手写笔与 ZUI 相机的推荐作用域与实际目标进程保持一致。
- ZUI 兼容代码已从基础 Hook 拆出，仅由独立 ZUI Hook 提供。

## 安装或升级

请使用同一 v3.2.0 Release 中的产物。先安装主修复模块和 BaseFix Hook，再按需增加其他组件；使用完整 3.x 方案时，请先成对刷入配套的 `boot` 与 `vendor_boot`。

模块选择、安装顺序和回退方式见 [README](../README.md)。

## 兼容性

- 目标设备：联想小新 Pad Pro GT（TB710FU / SM8650Q / pineapple）。
- ROM：ColorOS 16 移植包 OPD2513。
- ZUI 相机移植仅适用于 TB710FU。
