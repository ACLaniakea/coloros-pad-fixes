# v4.0.0

v4.0.0 是面向 TB710FU / SM8650Q 的稳定基线发布。全部正式 KernelSU 模块与配套 APK 统一为 `4.0.0 / 400000`，并以已在设备上运行验证的 `droidspaces-r1` 内核作为唯一正常安装内核。

> [!WARNING]
> 正常安装仅刷入 `boot-ACLaniakea-SM8650Q-droidspaces-r1.img`。Release 中的 `vendor_boot-ColorOS16-original-TB710FU.img` 是原始 ColorOS 回退镜像，**只**可与同来源原始 boot 一同用于回退，不能与本版本 boot 混刷。

## 相比 v3.2.1

### 性能与内存

- 恢复并保留 ColorOS 原厂的 HybridSwap、内存扩展、性能 HAL、WALT 与 cpuctl 路径；不再由模块覆盖 swappiness 或水位线。
- 修复移植框架的可选 UAF QoS 子调度器：设备缺少与运行时资源匹配的策略表，原先会在 system_server 反复查询空策略。现在按原厂参考机的回退语义跳过这一路失败分支，不影响正常 OSense、HybridSwap、性能 HAL 或 WALT 调度。
- `HMBIRD/sched_ext` 未作为正式功能启用。其试验代码、候选镜像与验证记录已移至 `experimental/kernel-sched-ext/`，不会进入模块或 Release 安装链。

### 稳定性与硬件链路

- 延续相机 Provider 的 SIGPIPE 防护、CamX 动态深度标签兼容，以及 AON 与普通相机的生命周期仲裁。
- 延续 CryptoEng 10003 分流实现，查找设备、密码本与互传联系人继续由 `FixModule` 统一提供，避免旧独立 HAL 模块竞争服务。
- 延续手写笔 BLE/HID、电量/充电/磁吸状态与触觉桥接；手写笔 Root 模块、Hook 与控制 APK 同步升级。
- ZUI 原厂相机移植与独立兼容 Hook 同步升级，仍仅做应用级兼容，不替换相机 HAL。

## 发布文件

| 文件 | 作用 |
|---|---|
| `boot-ACLaniakea-SM8650Q-droidspaces-r1.img` | 正式、已验证的 4.0.0 boot 内核；正常安装只刷此文件。 |
| `vendor_boot-ColorOS16-original-TB710FU.img` | 原始 ColorOS vendor_boot，仅供与原始 boot 成套回退。 |
| `FixModule-v4.0.0.zip` / `BaseFix-Hook-v4.0.0.apk` | 主修复、CryptoEng、AON/相机/性能兼容。 |
| `OplusBSP-Modules-v4.0.0.zip` | BSP 内核模块。 |
| `PenBridge-Module-v4.0.0.zip` / `PenBridge-Hook-v4.0.0.apk` / `PenHidCtl-v4.0.0.apk` | 手写笔三件套。 |
| `SM8650Q-Scene-Scheduler-v4.0.0.zip` | Scene 的 SM8650Q 专用调度配置。 |
| `LenovoPadProGT-ZUI-Camera-Port-v4.0.0.zip` / `ZUI-Camera-Compat-v4.0.0.apk` | 按需安装的 ZUI 原厂相机移植。 |

`PortTuning-Module` 已废弃且不再发布；其策略已由主修复中恢复的原厂内存与性能路径替代。

## 安装或升级

1. 备份现有 `boot`、`vendor_boot` 和 KernelSU 配置。
2. 在 bootloader 中仅刷入 `boot-ACLaniakea-SM8650Q-droidspaces-r1.img`，然后重启系统。
3. 通过 KernelSU 安装 `FixModule` 与 `OplusBSP-Modules`；手写笔、Scene、ZUI 相机按需安装。
4. 覆盖安装需要的 LSPosed Hook 与 APK，并按 README 的推荐作用域启用。
5. 执行一次完整重启。不要单独重启 zygote。

完整命令、回退边界和 SHA-256 见项目 [README](../README.md) 与 Release 附件说明。
