# v4.0.0

面向 TB710FU / SM8650Q 的稳定基线发布。全部模块与配套 APK 统一为 `4.0.0 / 400000`，并以已在设备上验证的 `droidspaces-r1+` 内核与阻塞版 vendor_boot 作为唯一正常引导链。

> [!WARNING]
> 必须成对刷入 `boot-ACLaniakea-SM8650Q-droidspaces-r1.img` 与 `vendor_boot-hyperSched-stub.img`。`vendor_boot-ColorOS16-original-TB710FU.img` 是原始 ColorOS 回退镜像，**只**能与同来源原始 boot 一同用于回退，不可与本版本 boot 混刷。

## 相比 v3.2.1

### 交还原厂内存与性能路径

- 恢复并保留 ColorOS 原厂的 HybridSwap、内存扩展、性能 HAL、WALT 与 cpuctl 路径，模块不再覆盖 swappiness 或水位线。
- 修复移植框架的 UAF QoS 子调度器：设备缺少匹配的策略表，原先会让 system_server 反复查询空策略；现按原厂参考机的回退语义跳过该失败分支。
- `HMBIRD/sched_ext` 未作为正式功能启用，相关试验代码与镜像移至 `experimental/kernel-sched-ext/`，不进入 Release 安装链。

### r1+ 内核与 DroidSpaces

- 正式内核升级为 `6.1.128-android14-11-sm8650q-droidspaces-r1+`，补齐 DroidSpaces 所需的 User / PID / IPC / Network / Time namespace 与 `SYSVIPC`、POSIX 消息队列。
- 保留并验证容器运行链所需的 `ANDROID_BINDERFS`、ashmem/memfd shim、`OverlayFS`、`FUSE`/FUSE-BPF、`seccomp`、`io_uring`、cgroup freezer、PSI 与 tmpfs ACL/xattr。
- 显示与音频仍由 DroidSpaces/AnLand 的 Android 侧桥接负责，本 Release 不宣称将其编入内核。
- 调度基线不变：sched_ext 与 HMBIRD 仍是隔离实验，未进入 r1+。

### 稳定性与硬件链路

- 延续相机 Provider 的 SIGPIPE 防护、CamX 动态深度标签兼容，以及 AON 与普通相机的生命周期仲裁。
- 延续 CryptoEng 10003 分流，查找设备、密码本与互传联系人由 `FixModule` 统一提供。
- 延续手写笔 BLE/HID、电量/充电/磁吸状态与触觉桥接；手写笔三件套同步升级。
- ZUI 相机移植与兼容 Hook 同步升级，仍仅做应用级兼容，不替换相机 HAL。

> [!NOTE]
> `PortTuning-Module` 已废弃且不再发布，其策略由主修复中恢复的原厂内存与性能路径替代。

## 安装或升级

1. 备份现有 `boot`、`vendor_boot` 与 KernelSU 配置。
2. 在 bootloader 中依次刷入本版 `boot` 与 `vendor_boot`，重启。
3. 通过 KernelSU 安装 `FixModule` 与 `OplusBSP-Modules`；手写笔、Scene、ZUI 相机按需安装。
4. 安装所需 LSPosed Hook 与 APK，按 README 的推荐作用域启用。
5. 执行一次**完整重启**，不要仅重启 zygote。

完整命令、回退边界与 SHA-256 见 [README](../README.md)。
