# Lenovo ZUI Camera (TB710FU Stock)

Systemless installation of the Lenovo-signed ZUI Camera 18.0.1.251216192500,
Camera Assistant, and QR scanner extracted from the TB710FU ZUI 17.5.04.414
factory image. The original priv-app permission allowlists are included.

This module deliberately does not replace camera HAL, CamX libraries, kernel
drivers, or the currently installed camera application. It can therefore be
uninstalled cleanly if the app is not compatible with the active camera stack.
